cards. This run checks that path on a real card, for spec 010's changes and for spec 009's, which
deferred its check to here. The benches' own reports are
[2026-10-25-runtime-torch.md](2026-10-25-runtime-torch.md) and

programs' changes land in it, and the margin's 1,611 MB floor covers it either way.

## Seen, not failures

- During `bench:fit`'s step 3 (another program holding memory), the torch runtime printed torch's
  own `UserWarning: Failed to initialize NumPy: No module named 'numpy'`. The runtime ships no
  numpy, and the step finished as designed.
- torch's out-of-memory messages list every process on the card at "17179869184.00 GiB": that is
  torch printing the WDDM driver's "not available", not a measure. The bench reads the request,
  the free memory and the cap correctly from the same message.
